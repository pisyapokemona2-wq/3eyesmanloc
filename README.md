# ТРЕТИЙ ГЛАЗ — приключения Мицу

Ремейк NES-игры **Mitsume ga Tooru / 3 Eyes Boy** (1992) по манге Осаму Тэдзуки для современных
мониторов: настоящий пиксель-арт в духе лучших 16-битных игр, 8 этапов, 8 боссов и способности,
которые открываются по ходу игры.

- Внутреннее разрешение **480×270**, на 1080p — ровно **×4** (чёткие пиксели, без размытия).
- Чистый JavaScript + Canvas 2D + WebAudio. Никаких внешних файлов-ассетов: весь арт — спрайты
  в виде строк в `src/art/*.js`, музыка и звуки синтезируются.

## Запуск (Windows)

Скачайте **ThirdEye.exe** со страницы Releases (релиз «game» — последняя сборка):
https://github.com/pisyapokemona2-wq/3eyesmanloc/releases/download/game/ThirdEye.exe

Это один файл (~4 МБ), установка не нужна. Нужен Windows 10/11 (движок WebView2 встроен в систему).
F11 или Alt+Enter — окно / полный экран.

Сборка вручную: `node tools/build-exe-lite.js` → `dist/ThirdEye.exe` (Neutralino, игра вшита в exe).
Каждый push собирает exe в GitHub Actions и обновляет релиз «game».

Для разработки можно просто открыть `index.html` в браузере.

## Управление

Две схемы, переключаются в меню **Управление**; там же любое действие можно переназначить на любую клавишу или кнопку мыши.

| Действие | Классика | WASD + мышь |
|---|---|---|
| ходьба | ← → | A D |
| прыжок (дольше держишь — выше) | Z / Пробел / ↑ | Пробел / W |
| присесть; удар сверху в прыжке | ↓ | S |
| выстрел третьим глазом, удерживать — заряд * | X | ЛКМ (летит в сторону прицела) |
| выстрел вверх * | A | — (целишься мышью) |
| копьё «Красный Кондор»: бросить / вернуть | C | ПКМ |
| рывок * | Shift | Shift |
| пробуждение третьего глаза * | V | E |
| пауза | Esc / P | Esc / P |

F1 — бессмертие (бесконечные жизни, с флажка), F2 — неуязвимость (для тестов).

\* — открывается по ходу игры. Поддерживаются геймпад и сенсорное управление.

## Способности (открываются после боссов)

| После этапа | Способность | Что даёт |
|---|---|---|
| старт | Красный Кондор | копьё бьёт врагов, ломает кирпичи, втыкается в стену и становится ступенькой |
| 1 | Взгляд третьего глаза | стрельба, в т.ч. вверх по диагонали |
| 2 | Двойной прыжок | второй прыжок в воздухе |
| 3 | Рывок | неуязвимый рывок, пробивает треснувшие стены |
| 4 | Заряд взгляда | пробивающий выстрел, ломает щиты стражей |
| 5 | Прыжок от стен | скольжение по стенам и отскок — вертикальные шахты |
| 6 | Удар с небес | крушит окованные блоки, оглушает врагов волной |
| 7 | Пробуждение глаза | 10 с неуязвимости и шквального огня |

В ранних этапах спрятаны секреты (окованные блоки, треснувшие стены) — их можно открыть, вернувшись
через «Выбор этапа» с новыми способностями.

## Этапы

1. **Крыши Токио** — Стальной Бык
2. **Канализация** — Крокодил-мутант
3. **Руины джунглей** (вода, плавание) — Каменный Идол
4. **Кристальные пещеры** (темнота, освещение) — Кристальный Паук
5. **Ледяная гора** (скользкий лёд) — Ледяной Голем
6. **Огненная гора** (лава, шахты) — Огненный Змей
7. **Небесный храм** (восходящие потоки) — Механический Гаруда
8. **Храм Заркуна** — Принц Заркун (две формы)

Между этапами — лавка мастера: сердца, улучшения выстрела и копья, обереги, жизни.

## Структура

```
index.html             холст, сенсорные кнопки, подключение скриптов
ART_GUIDE.md           стайлгайд и формат спрайтов
src/art/registry.js    реестр пиксельных спрайтов (строки → холсты, анимации)
src/art/*.js           весь арт: герой, враги, боссы, предметы/UI/эффекты, тайлсеты 8 тем
src/bg_themes.js       процедурные пиксельные параллакс-фоны 8 тем
src/pix.js             пиксельные примитивы без сглаживания
src/gfx.js             буфер 480×270, целочисленное масштабирование, пиксельный текст
src/levels.js          ASCII-куски уровней и описание 8 этапов (легенда в начале файла)
src/world.js           тайлы, сборка уровня, физика
src/tiles.js           автотайлинг и отрисовка тайлов
src/player.js          герой и все способности
src/enemies.js         19 типов врагов
src/bosses.js          8 боссов
src/ui.js, src/game.js интерфейс, состояния, камера, освещение
tools/                 превью арта: sheet.js (лист спрайтов), bg.js (фоны), check-art.js
```

Проверка арта: `node tools/check-art.js`; лист спрайтов: `node tools/sheet.js hero_ out.png 4`.
