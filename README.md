# ТРЕТИЙ ГЛАЗ — приключения Мицу

2D-платформер в духе японских экшенов начала 90-х про мальчика с третьим глазом —
с высоким разрешением, плавной анимацией и множеством деталей.

Игра написана на чистом JavaScript + Canvas 2D + WebAudio, **без единого внешнего ассета**:
вся графика (персонажи, тайлы, фоны), музыка и звуки генерируются кодом.
Поэтому картинка остаётся чёткой на любом экране — от телефона до 4K.

## Как запустить

Просто откройте `index.html` в браузере (Chrome, Firefox, Edge, Safari).
Сервер и сборка не нужны. Для пиксельного шрифта нужен интернет (Google Fonts);
без него игра работает со стандартным моноширинным шрифтом.

По желанию можно запустить локальный сервер:

```bash
npx http-server . -p 8080
```

## Управление

| Клавиша | Действие |
|---|---|
| ← → / A D | ходьба |
| ↓ | присесть; ↓ + прыжок — спрыгнуть с платформы |
| Z / Пробел | прыжок (дольше держишь — выше прыжок) |
| X | выстрел третьим глазом; удерживай для **заряженного** выстрела |
| ↑ + X | стрельба по диагонали вверх |
| C | бросить копьё «Красный Кондор» / вернуть его |
| V | **открыть третий глаз**, когда шкала заполнена |
| Esc / P | пауза |

Поддерживаются геймпады (стандартная раскладка) и сенсорное управление на телефонах.

## Механики

- **Выстрел глазом** — быстрые зелёные лучи; удержание X копит заряд для пробивающего сгустка.
- **Копьё «Красный Кондор»** — бьёт врагов, ломает кирпичи, а воткнувшись в стену,
  становится платформой. Так можно забраться туда, куда не допрыгнуть.
- **Третий глаз** — шкала копится за победы над врагами и зелёные сферы энергии.
  Полная шкала + V: 10 секунд неуязвимости, тройной беглый огонь и магнит для монет.
- **Монеты** выпадают из врагов, бонус-блоков и кирпичей. Их тратят в лавке мастера между этапами:
  сердца, улучшения выстрела и копья, обереги, жизни.
- Чекпоинты-статуи, движущиеся и осыпающиеся платформы, пружины, шипы, лава.
- Прыжок сверху оглушает большинство врагов (кроме колючих и огненных).

## Этапы и боссы

1. **Город на закате** — Стальной Бык (таранит стены, обрушивает потолок)
2. **Древние руины** — Каменный Идол (веер огня, удары о землю)
3. **Кристальные пещеры** (темнота с динамическим освещением) — Кристальный Паук
4. **Огненная гора** — Огненный Змей (выныривает из лавы)
5. **Храм Заркуна** — Принц Заркун (колдун-телепортёр, во второй фазе — трёхглазый демон)

Прогресс (открытые этапы, громкость, рекорд) сохраняется в `localStorage`.

## Структура кода

```
index.html          — холст, сенсорные кнопки, подключение скриптов
src/core.js         — константы, утилиты, сохранение
src/input.js        — клавиатура, геймпад, тач → «действия»
src/audio.js        — синтез звуковых эффектов и чиптюн-секвенсор с 9 треками
src/gfx.js          — масштабирование под экран (devicePixelRatio), примитивы, текст
src/particles.js    — пыль, искры, взрывы, всплывающий текст
src/levels.js       — ASCII-куски уровней и описание 5 этапов
src/world.js        — тайловая карта, сборка уровня, физика и столкновения
src/tiles.js        — отрисовка тайлов по темам (с кэшем в разрешении экрана)
src/backgrounds.js  — процедурные параллакс-фоны
src/entities.js     — монеты, предметы, чекпоинты, платформы, снаряды
src/player.js       — герой: скелетная анимация, выстрелы, копьё
src/enemies.js      — 7 типов врагов
src/bosses.js       — 5 боссов с фазами
src/ui.js           — HUD, меню, магазин, экраны этапов, финал
src/game.js         — состояния игры, камера, освещение, главный цикл
src/main.js         — запуск: фиксированный шаг 60 Гц
```

### Как добавить свой уровень

Уровень — это список кусков из `G.CHUNKS` (см. легенду символов в начале `src/levels.js`).
Нарисуйте новый кусок ASCII-строками и добавьте его имя в `chunks` нужного этапа.
Последним куском должна идти арена (`arena`, `arenaLava` или `arenaSky`).
